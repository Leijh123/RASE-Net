# Source provenance

`source_manifest.json` identifies the relative source snapshot, original SHA256, packaged SHA256 and path-only edits. Original server directories are kept in a private audit outside this repository. Leading scientific comments and upstream copyright headers are preserved.

The `original` snapshot is the historical IMIS-derived framework; `matched` is the recent BTCV component framework. Public canonical model exports use the latter where explicitly stated. No single performance table is claimed to have been regenerated by this organization-only change.
